# Notes Manager

Aplicación web para registrar, consultar, editar y organizar notas personales.

## Objetivo

Desarrollar una prueba de concepto (POC) que permita evaluar las capacidades de los agentes de desarrollo asistido por inteligencia artificial mediante Spec-Driven Development (SDD) simplificado.

## Stack tecnológico

- Node.js 26
- Next.js
- TypeScript
- Tailwind CSS
- Firebase Cloud Firestore
- Vercel

El detalle técnico se encuentra en [architecture.md](docs/architecture.md).
